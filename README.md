# Compliance--Correctness Decomposition for Post-Training Evaluation

This repository contains the manuscript source, paired evaluation records, analysis code, and derived artifacts for the Compliance--Correctness Decomposition (CCD) study of small language models before and after supervised fine-tuning (SFT).

CCD separates three evaluator-facing quantities:

- **Compliance (`F`)**: whether a response satisfies the required output contract.
- **Correctness (`C`)**: whether the extracted answer or executed program is judged correct by the stated instrument.
- **Strict success (`S`)**: whether a response is both compliant and correct.

The supplied evidence contains **49,140 matched pre/post response pairs**, **14 checkpoints**, **four benchmarks**, **nine inference configurations**, **495 evaluation cells**, and **55 model--dataset blocks**. Under equal-cell aggregation, strict success changes by **+12.12 percentage points (pp)** and compliance by **+34.78 pp**, giving a **+22.66 pp** change in the valid-but-wrong share (`Delta F - Delta S`). Parser-derived correctness changes by **+3.57 pp** and is reported separately because it depends on fallback extraction. On the 11,700-pair MBPP functional subset, pass@1 changes from **18.99% to 15.33%**.

These are descriptive, paired audit results. They do not establish that formatting caused capability change.

## Quick start

Create an isolated Python environment and install the analysis dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-analysis.txt
```

Validate the supplied records:

```bash
python scripts/validate_artifacts.py
```

Regenerate the CCD summaries and figures:

```bash
python analysis_ccd_revision.py
```

Regenerate the secondary revision analyses:

```bash
python revision_priority_analysis/revision_priority_analysis.py
```

Compile the manuscript:

```bash
cd paper
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The tracked `paper/paper.pdf` is a compiled snapshot. A local compilation produces `paper/main.pdf`, which is ignored by Git.

## Evidence and scope

The repository reproduces the reported post-hoc evaluation analyses from retained outputs. It does **not** reproduce every training and generation run end to end. Complete training-dose metadata are available for only 5 of the 55 model--dataset recipes, no additional training seeds are supplied, and the parser-validation sample has not been independently annotated or adjudicated. See [`docs/KNOWN_LIMITATIONS.md`](docs/KNOWN_LIMITATIONS.md) and [`docs/EVIDENCE_MAP.md`](docs/EVIDENCE_MAP.md).
